# بازسازی ریل ۰۲

ورودی اصلیِ بدون تغییر در `input/scenarios/scenario-02.json` بایگانی شده است. ورودی فعال `input/scenario.json` همان متن‌ها را دارد و فقط سه کلید انتخاب خط تولید اضافه شده‌اند: `reelId: "02"`، `renderer: "trailer"` و `audioStyle: "cinematic"`.

از ریشهٔ مخزن:

```bash
python3 -m venv .venv
.venv/bin/pip install -r kit/audio/requirements.txt
cd kit/render
npm ci
./run.sh --test
npm run stills
npm test
./run.sh
../../.venv/bin/python verify_video.py
npm run export
npm run test:web
npm start
```

خروجی scratch در `kit/out/02/`، خروجی‌های قابل‌تحویل در `kit/deliverables/reel-02/` و MP4 قابل‌ثبت در Git در `kit/deliverables/nail-reel-02.mp4` است. هیچ‌کدام از این دستورها فایل ریل اول را تغییر نمی‌دهند.

## خط تولید

- `src/index.html`: بارگذاری ماژول صحنه بر اساس ورودی؛ فونت‌های محلی، صفحه‌بندی اندازه‌گیری‌شده، هایلایت کلمه‌به‌کلمه و safe zone. برای تریلر، متن timing که با ورودی نخواند صریحاً خطا می‌دهد تا ویدیوی کهنه ساخته نشود.
- `src/scenes/trailer.js`: طراحی دو قهرمان، سه دشمن، درهٔ اثرانگشتی، نور، letterbox، ذرات و هشت صحنه. تمام حرکت فقط تابع `t` است.
- `audio/cinematic_audio.py`: زمان‌بندی ۳۴ ثانیه‌ای و موسیقی سینمایی کاملاً سنتزشده، با seed ثابت 207؛ بدون صدای انسان، TTS، sample یا آهنگ دانلودشده.
- `render/lib.mjs`: مسیرهای جداگانهٔ پروژه، Chromium باندل‌شده از npm، CPU Skia برای SVG و سرور با پشتیبانی از Range requests.
- `render/render.mjs`: seek در 30fps، screenshot واقعی 1080×1920، encode رنگ محدود BT.709 و H.264 High / yuv420p، AAC 48kHz، faststart.
- `render/trailer-stills.mjs`: فریم واقعی، کاور، شیت کاراکترها و تصاویر هر صحنه.
- `render/qa.mjs`: seek تصادفی/تکراری، تمام ۵۲ کلمه، محدودهٔ امن، فونت، نبود ایموجی، CSS animation و مرز لوپ.
- `render/verify_video.py`: دیکد کامل MP4، کدک/اندازه/fps/صوت/قله/حجم و ترتیب اتم‌های faststart.
- `render/preview-test.mjs`: متادیتای پخش، دانلودها، Range/416، گالری و نبود overflow موبایل.

## ویرایش

متن صحنه‌ها در JSON ویرایش می‌شود؛ مدت‌های مخصوص این ریل در `DURS` در فایل صوت سینمایی هستند. تغییر زمان نیازمند بازسازی صدا، timing، تصاویر و ویدیو است. کد حرکتِ هر صحنه با زمان محلی آن تنظیم شده؛ برای تغییر زیاد مدت، ضرب‌های حرکتی را هم تنظیم کنید.

پالت نهایی در gradientها و توابع `trailer.js` است. هندل از `brand.json` خوانده می‌شود. نسخهٔ سینمایی به‌صورت عمدی **instrumental-only** است؛ تغییر `brand.voice.enabled` به‌تنهایی به این ریل گوینده اضافه نمی‌کند.

پیش‌نمایش فعلی برای ریل ۰۲ طراحی شده و دانلود ریل قبلی نیز در آن موجود است. برای بازسازی منابع ریل اول، JSON بایگانی‌شدهٔ `scenario-01.json` را ورودی فعال کنید؛ موتور studio و موسیقی‌ساز قبلی حفظ شده‌اند. دستور export برای پروژهٔ ۰۱ از مسیر قدیمی `out/` استفاده می‌کند. بازسازی ریل اول را در اجرای جداگانه انجام دهید، نه هم‌زمان با رندر ۰۲؛ ورودی فعال و snapshot مرورگر باید ثابت باشند.

## محدودیت‌ها

تریلر کارتونی و فانتزی است، نه ادعای شکست‌ناپذیری ناخن با ژل و نه آموزش استفاده از UV. صدا با حس سازهای بادی/زهی سنتزشده، نه ضبط یک ارکستر واقعی. زیرنویس با زمان خواندن هماهنگ است؛ گفتاری برای forced alignment وجود ندارد. سه‌رخِ کاراکترها سبک‌پردازی‌شدهٔ دوبعدی است. لوپ تصویری دقیق، اما اتصال موسیقی تضمینِ loop sample-perfect ندارد. تضمینی برای بازدید وجود ندارد.
