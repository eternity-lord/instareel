# ریل ۰۳ — ناخن شمارهٔ ۸: انتقام استون

## کارگردانی
۳۹ ثانیه، ۱۰ صحنه + پایان‌بندی ۳ثانیه‌ای. ادامهٔ جهان و طراحی ریل ۰۲، اما هر ۲–۳ ثانیه یک ضرب حرکت واضح‌تر: ضربهٔ عنوان، dolly-zoom، عبور جرثقیلی، power-slide، barrel-roll کامل، موج مه، orbit دوبعدیِ عمق‌دار، سپر، غافلگیری و match cut. کمدیِ بامزه، بدون ترس یا جراحت. زیرنویس صاف و خوانا می‌ماند؛ رول فقط روی دنیای تصویر است. عنوان اضافهٔ بالای فیلم حذف‌شده باقی می‌ماند.

## صداقت و ایمنی
موسیقی سینمایی سنتزشده، بدون ضبط ارکستر/صدای انسان یا آهنگ خارجی. هایلایت زمان خواندن است، نه هم‌ترازی گفتار. محوشدن رنگ فقط افکت فانتزیِ لاک است، نه آسیب بدن. سپر تاپ‌کت و مقابله با استون ادعای علمی یا راهنمای استفادهٔ مواد نیست؛ توضیح در کپشن و گزارش درج می‌شود. از فلاش تمام‌صفحهٔ متوالی استفاده نمی‌شود. بازدید قابل تضمین نیست.
