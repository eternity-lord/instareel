نسخهٔ مستقل `kit/deliverables/nail-reel-08-recut.mp4`؛ نسخهٔ ۳۲ثانیه‌ای قبلی `nail-reel-08.mp4` عیناً باقی است. سناریوی اصلی پیوست و snapshot فعال قبلی تغییر نکرده‌اند؛ snapshot اجرایی تازه `input/scenarios/scenario-08-recut-active.json` است. ورودی فعال به این تدوین اشاره می‌کند.

ترتیب کار: جست‌وجوی منابع اولیه و دانشگاهی → نوشتن `research/reel-attention-research.md` → نوشتن `EDITING-PLAYBOOK.md` → ثبت طرح تدوین و SHA256 دو فایل در `research/reel-08-edit-plan.json` → کد انیمیشن تازه → تست و رندر. تست مخصوص، hash دو سند برنامه‌ریزی را کنترل می‌کند؛ این ثبت محلی جای timestamps مستقل یا آزمایش تجربی را نمی‌گیرد.

## محدودیت‌ها

- این فایل **انیمیشن برداری ۲٫۵بعدی** است، نه شبیه‌سازی فیزیکی/رندر حجمی 3D. زمان‌بندی واژه‌ها برای خواندن است، نه forced alignment صدای غایب.
- موسیقی بی‌کلام به‌صورت محلی با سینوس‌های نرم/آرپژ تولید شده؛ فایل موسیقی خارجی داده نشده است. مسیر اختیاری `audio/music.*` کیت v3 همچنان مقدم است. ثبت audio-status مشخص می‌کند کدام مسیر واقعاً استفاده شده.
- حلقهٔ **تصویری** فریم آخر/اول در DOM و raster آزموده می‌شود. fade پایان صوت عمدی است؛ seamless loop موسیقی ادعا نمی‌شود.
- کارت بدنه ثابت دارد؛ کاراکتر تزئینی و پس‌زمینه همچنان می‌توانند حرکت ملایم داشته باشند.
- برخی ابزارها و آیکن‌ها از سبک قبلی برای ثبات جهان استفاده می‌کنند؛ همهٔ نماهای تدوین تازه در `src/scenes/quiz-recut.js` جدا ثبت شده‌اند. renderer و فایل صوت قدیمی ۰۸ دست‌نخورده‌اند.
- جای‌گذاری اکسپلور، افزایش retention/فالو/فروش تضمین نیست. به حساب/Insights دسترسی نداریم؛ انتشار انجام نشده است.

## بازتولید

```sh
npm ci --prefix kit/render
python3 -m venv .venv
.venv/bin/pip install -r kit/audio/requirements.txt
.venv/bin/python kit/audio/make_audio.py
node kit/render/stills.mjs
node kit/render/qa.mjs
node kit/render/quiz-recut-test.mjs
.venv/bin/python kit/audio/test_music_source.py
node kit/render/render.mjs --test
node kit/render/render.mjs
.venv/bin/python kit/render/verify_video.py
```

`render/run.sh` برای آماده‌سازی وابستگی/فونت و رندر فعلی هم قابل‌استفاده است. پس از ساخت، REPORT و storyboard به مسیر out کپی و `export.mjs` اجرا شود. برای وب `node kit/render/preview-test.mjs` را پس از export اجرا کنید. MP4، QA و شیت منتخب در `docs/evidence-08-recut/`/deliverables حفظ می‌شوند؛ فایل‌های موقت out به Git اضافه نمی‌شوند.

## نتایج نهایی کنترل کیفیت

- decode کامل: **870 فریم / 29 ثانیه**؛ 1080×1920، 30fps، H.264 High/yuv420p، AAC stereo 48kHz، faststart.
- حجم: **6,787,031 bytes**؛ SHA256: `2957b16d9401d608bed8800843d9913ea0a2ca9dd7d0d29206815396ac61302f`.
- فایل نهایی پس از AAC: peak **-9.9 dBFS**؛ بدون clipping.
- master WAV: **-19.96 LUFS**، true peak **-9.90 dBTP**؛ بدون گوینده، موسیقی محلی synthesized، SFX محدود.
- QA عمومی: **48 واژه**، صفحات متن و ناحیهٔ امن، فونت محلی، بدون heading اضافه، صفر CSS animation خودکار و صفر خطای مرورگر.
- حلقهٔ تصویری: DOM و تصویرِ نمونهٔ آخر/اول یکسان (max channel delta 0).
- تست اختصاصی: ۴۵ زمان مختلف و ترتیب seek معکوس؛ SVG finite و همهٔ references معتبر؛ کارت ثابت از .3 تا 3.6 ثانیه؛ hash تحقیق/راهنما؛ حفظ hash هر هفت MP4 قبلی از جمله ۰۸ اصلی.
- ۹ تست importer موسیقی v3 پاس شد (MP3/M4A، loop/trim، silence/disabled/error و اجرای کامل quiz بدون voice).
- smoke سه‌ثانیه‌ای و رندر کامل پاس شدند. QA وب: metadata، دانلود و range، پاسخ 416، lightbox، موبایل بدون overflow و صفر خطای مرورگر.
- مرور بصری: فریم اول، تیپ دیررس، دوست، ابزار، کارت، CTA و شیت ۲۴فریمی خروجی بررسی شدند. این بررسی با دادهٔ رفتار واقعی مخاطب یا ارزیابی با گوشی کاربر یکی نیست.
