- راهنمای `kit/README.md` با نسخهٔ جدید هماهنگ و یادداشت روشن اولویت‌های فعلی در ابتدای آن اضافه شد.

- قابلیت ترک موسیقی محلی جدید در **همهٔ مسیرهای صوتی تولید فعلی** ادغام شد، نه فقط اسکریپت نمونهٔ ZIP: generic، cinematic، journey، macro voiced/music-only، education و quiz.
- `kit/audio/music_source.py` پشتیبانی مشترک mp3/wav/m4a، تقدم mp3→wav→m4a، loop/trim، resample استریو، gain تنظیم‌پذیر، fade-out و ثبت منبع/هش را فراهم می‌کند. صدا/افکت دست‌نخورده باقی می‌ماند و ducking/master همان مسیر بعد از انتخاب bed انجام می‌شود.
- فایل صوتی خراب/تنظیم gain نامعتبر خطای واضح می‌دهد. فایل‌های محلی با FFmpeg و بدون shell یا دسترسی پروتکل شبکه decode می‌شوند؛ در نبود FFmpeg سیستم از imageio-ffmpeg موجود استفاده می‌شود.
- `audio-status.json` جدید فیلد `musicSource` دارد: `synthesized` / `external-local` / `disabled`. فایل موسیقی واقعی یا API موسیقی در ZIP موجود نیست و هیچ سرویس موسیقی فراخوانی نشده است.

- نسخهٔ engine/render/dependencies داخل ZIP یک اسکلت قدیمی‌تر است. جایگزین موتور قابل‌seek، رندر تست‌شده، lockfile، FFmpeg محلی و مسیرهای مستقل ریل‌های موجود نشد؛ فقط قابلیت جدید موسیقی به موتور فعلی منتقل شد.
- اصلاح قبلیِ نبود عنوان اضافه بالای زیرنویس و قواعد محتوای محتاطانه محفوظ‌اند. وعدهٔ قدیمی «هفته‌ها» در voice prompt نمونه، مجوز برگرداندن ادعای ماندگاری قطعی نیست.

## آزمون‌ها

`kit/audio/test_music_source.py`: **۹ تست پاس**:

1. نبود فایل = بازگشت همان آرایه، بدون تغییر؛
2. music disabled = سکوت و عدم decode حتی فایل خراب؛
3. WAV مونو کوتاه → loop/resample/stereo/gain/fade و عدم تغییر ورودی؛
4. کوتاه‌کردن ترک بلند؛
5. decode واقعی MP3/M4A و تقدم سه فرمت؛
6. ترک ساکت بدون NaN؛
7. gain منفی/بزرگ/NaN رد می‌شود؛
8. فایل خراب خطای صریح دارد؛
9. اجرای کامل مسیر quiz با ترک موقت در tempdir، ۳۲ ثانیه stereo، افکت‌ها محفوظ، **بدون گوینده** و ثبت provenance.

همهٔ fixtureهای صوتی در پوشهٔ موقت تولید و پاک شدند؛ هیچ ترک تستی در `audio/music.*` یا گیت نگه‌داری نشده است.

صوت سناریوی فعال ۰۸ بدون فایل موسیقی، قبل و بعد از تغییر دوباره تولید و hash مقایسه شد: **بایت‌به‌بایت یکسان**، SHA256 WAV برابر `ec33386ac022365847c6ae312e9232ae2c17d6209008febfa52a862eb488ed2b`. metadata جدید فقط منبع را اضافه می‌کند؛ صدا تغییر نکرده است.

تمام هفت MP4 قبلی + brand، سناریو، کپشن، package-lock، run.sh و index.html با محتوای قبل مقایسه شدند: **بدون تغییر**. هر ۱۷ فایل بایگانی با manifest تطبیق داده شد. Python compile و `git diff --check` پاس شدند. رندر ویدئوی تازه لازم نبود و اجرا نشد؛ در این نوبت ادعای QA بصری جدید یا هم‌ترازی گفتار نداریم.

## اجرای بعدی

پرامپت موسیقی مناسب عنوان سناریو را از `music-prompts.md` انتخاب کنید؛ در صورت تهیهٔ موسیقی بی‌کلامِ مجاز آن را در `kit/audio/music.mp3`، `.wav` یا `.m4a` بگذارید و BPM را با ترک هماهنگ کنید. تولید صوت همان دستور فعلی است:

```bash
.venv/bin/python kit/audio/make_audio.py
.venv/bin/python kit/audio/test_music_source.py
```

برای اجرای کامل تصویر/export از راهنمای ریل فعال استفاده کنید. اضافه‌کردن فایل موسیقی به‌تنهایی هیچ MP4 نهایی را تغییر نمی‌دهد. مجوز تجاری و نبود وکال را صاحب فایل باید بررسی کند؛ کد نه حذف وکال می‌کند و نه حقوق موسیقی را تأیید می‌کند.
