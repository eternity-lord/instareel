## خروجی
۳۵ ثانیه، ۸ صحنه + پایان‌بندی ۳ثانیه‌ای، 1080×1920، 30fps، H.264 High / yuv420p، AAC stereo 48kHz. دو کاراکتر اصلی با تصویرسازی SVG، زیرنویس فارسی RTL کلمه‌به‌کلمه، موسیقی و افکت تولیدشده با کد.

**نسخهٔ فعلی بدون گوینده است.** سرویس TTS فارسی در محیط ساخت قابل‌دسترسی نبود؛ زمان‌بندی کلمات برای خواندن متن است، نه تطبیق با گفتار. این محدودیت در گزارش و پیش‌نمایش نیز مشخص است. بازدید یا وایرال‌شدن تضمین‌پذیر نیست.

فایل نهایی و تصاویر همراه در `kit/deliverables/` قرار می‌گیرند. فایل ویدیوی نهایی برای دانلود مستقیم در Git ثبت شده؛ سایر خروجی‌های حجیم وارد Git نمی‌شوند. همهٔ منابع و دستور بازسازی در مخزن موجودند. `kit/out/` فقط پوشهٔ کاری رندر است.

## راه‌اندازی و بازسازی

نیازمندی‌ها: Node.js 22+، Python 3.11+، Linux x64 برای مرورگر باندل‌شده. برای Chromium دلخواه، `CHROMIUM_PATH` را تنظیم کنید. FFmpeg سیستم خودکار تشخیص داده می‌شود؛ در نبود آن از باینری `imageio-ffmpeg` استفاده می‌شود (`FFMPEG_PATH` قابل‌تنظیم است).

```bash
python3 -m venv .venv
.venv/bin/pip install -r kit/audio/requirements.txt
cd kit/render
npm ci
./run.sh --test          # موسیقی، فونت‌های محلی و تست رندر ۳ثانیه‌ای
npm test                # seek تصادفی، هایلایت ۶۵ کلمه، فونت، محدوده امن و لوپ
npm run stills          # کاور، فریم نمونه، شیت کاراکتر و تصاویر صحنه‌ها
./run.sh                # رندر کامل ۱۰۵۰ فریم و contact sheet
../../.venv/bin/python verify_video.py
npm run export          # کپی خروجی نهایی از out/ به deliverables/
npm run test:web        # تست پخش/متادیتا، دانلود، گالری و موبایل
npm start               # پیش‌نمایش روی 0.0.0.0:3000
```

گزارش `kit/docs/REPORT.md` و استوری‌بورد در سورس نگه‌داری می‌شوند؛ رندر آن‌ها را به `out/` و export به خروجی نهایی کپی می‌کند. پورت پیش‌نمایش را می‌توان با `PORT` تغییر داد. پخش و دانلود ویدیو از URLهای نسبی انجام می‌شود؛ سرور Range requests را برای seek پشتیبانی می‌کند.

برای تست سریع بدون تلاش برای TTS: `NO_TTS=1 ./run.sh --test`. ساخت صوت با seed ثابت انجام می‌شود. اگر TTS دوباره در دسترس باشد، timing و مدت ریل تغییر می‌کند؛ تست بازهٔ ۲۸–۳۸ ثانیه را دوباره اجرا و متن گزارش را به‌روز کنید. برای تکرار **همین نسخهٔ موسیقی‌محور** از `NO_TTS=1` استفاده کنید.

## ویرایش

- `kit/input/scenario.json`: متن و ایدهٔ هر صحنه (سناریوی پیوست‌شدهٔ کاربر، بدون تغییر متن).
- `kit/input/post_copy.md`: کپشن و هشتگ پیشنهادی برای همین ریل.
- `kit/brand.json`: هندل، تنظیم موسیقی و صدای مصنوعی اختیاری؛ رنگ‌های نهایی تصویرسازی در `studio.js` هستند.
- `kit/src/scenes/studio.js`: طراحی اصلی دو کاراکتر، استودیو و هشت صحنه.
- `kit/src/index.html`: موتور زمان، صفحه‌بندی اندازه‌گیری‌شدهٔ زیرنویس و محدودهٔ امن.
- `kit/audio/make_audio.py`: موسیقی اورجینال، افکت‌ها، fallback صریح و زمان‌بندی.
- `kit/render/`: رندر، تست، استخراج تصاویر و سرور پیش‌نمایش.

تمام تصاویر از تابع خالص `window.__seek(t)` ساخته می‌شوند؛ انیمیشن CSS، تایمر و تصادف زمان اجرا وجود ندارد. برابری DOM در seek تصادفی دقیق تست می‌شود؛ آزمون تصویر تلورانس بسیار کوچک آنتی‌الیاسینگ SwiftShader دارد. فونت Vazirmatn با مجوز OFL است (`kit/assets/fonts/OFL.txt`). اثر تصویری یا موسیقی دانلودشدهٔ شخص ثالث استفاده نشده است.

شرح اولیهٔ کیت در `kit/README.md` و نمونهٔ مرجع قدیمی در `kit/reference/` حفظ شده‌اند؛ prototype قدیمی بخشی از رندر نهایی نیست.
