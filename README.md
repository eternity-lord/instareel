# instareel · آیدا نیل‌روم

پنج ریل اختصاصی فارسی برای **@ayda.nailroom**، بر اساس سناریوهای کاربر. تصویرسازی‌ها و موسیقی‌ها با کد ساخته شده‌اند؛ منبع خارجیِ تصویر/آهنگ یا صدای انسان واقعی استفاده نشده است. نسخهٔ فعلی ریل ۰۵ هم به درخواست کاربر بدون نریشن و با موسیقی ملایم بی‌کلام است.

## ریل ۰۵ — چرا ژل ناخن زود می‌پره؟ پنج دلیل رایج

طبق کیت جدید آپلودشده: **غیرکارتونی، بدون کاراکتر/پوست/چهره**، Three.js واقعی با MeshPhysicalMaterial، محیط استودیویی ساخته‌شده با کد، postprocessing و GSAP paused. تصویر ژل، فیلم نازک، مقایسهٔ ضخامت، لبهٔ آزاد و فشار مکانیکی؛ دیاگرام طلایی روی زمینهٔ مشکی.

**۳۸ ثانیه، ۸ صحنه + پایان‌بندی ۳ثانیه‌ای، 1140 فریم، 1080×1920 / 30fps، H.264 / AAC.** **نسخهٔ اصلاح‌شده: بدون نریشن و افکت، فقط موسیقی ملایم بی‌کلام اختصاصی 84 BPM** (پد گرم و آرپژ پیانومانند). تصویر، ۵۷ واژهٔ زیرنویس و زمان‌بندی قبلی دست‌نخورده‌اند؛ H.264 بدون بازرمزگذاری کپی شده و hash جریان ویدیو یکسان است.

## ریل ۰۴ — ناخن شمارهٔ ۹: از پا تا اوج

قصه‌ای گرم از شمارهٔ نُهِ خواب‌آلود: خروج از جوراب، عبور از دنیای کفش، اسپا با اردک حوله‌پوش، تغییر ظاهر یاسی با نگین، راه‌رفتن در ساحل و سایهٔ شستِ شمارهٔ ده. پورتال‌های تصویری سفر را به هم وصل می‌کنند. تصویرسازی 2.5D/SVG، نه رندر سه‌بعدی واقعی یا برداشت دوربین فیزیکی.

**۳۹٫۶ ثانیه، ۱۰ صحنه + کارت پایان ۳ثانیه‌ای، 1188 فریم، 1080×1920 / 30fps، H.264 / AAC.** موسیقی اختصاصی گرم با 100 BPM و افکت؛ بدون گوینده. ۷۰ کلمه با زمان‌خواندن، سه واژهٔ glow-up روی ضرب‌های 0/.6/1.2؛ عنوان کوچک اضافی بالای فیلم ندارد.

## ریل ۰۳ — ناخن شمارهٔ ۸: انتقام استون

دنبالهٔ پرتحرک با شمارهٔ هشت یاقوتی و سوهان اسکیتی، استونِ تک‌چشم، ارتش پنبه و شمارهٔ نُهِ خواب‌آلود. حرکت دوربین شامل تعقیب، چرخش کامل، دالی‌زوم و گردش دور گروه است؛ زیرنویس ثابت و خوانا می‌ماند. عنوان کوچک اضافه در بالای فیلم وجود ندارد.

**۳۹ ثانیه، ۱۰ صحنه + پایان‌بندی ۳ثانیه‌ای، 1170 فریم، 1080×1920 / 30fps، H.264 / AAC.** موسیقی و افکت اختصاصی، بدون گوینده؛ هایلایت ۶۴ کلمه زمان‌خواندن است، نه هم‌ترازی با گفتار.

## اجرای پروژهٔ فعال (۰۵)

نیازمندی‌ها: Node.js 22+، Python 3.11+ و Linux x64 برای Chromium باندل‌شده. `CHROMIUM_PATH` و `FFMPEG_PATH` در صورت نیاز قابل تنظیم‌اند. در نبود FFmpeg سیستم از باینری پکیج `imageio-ffmpeg` استفاده می‌شود.

```bash
python3 -m venv .venv
.venv/bin/pip install -r kit/audio/requirements.txt
cd kit/render
npm ci
./run.sh --test          # ساخت صوت + تست ۳ثانیه‌ای
npm run stills          # کاور، فریم واقعی، شیت کاراکتر، تصاویر صحنه‌ها
npm test                # seek، تمام کلمات، safe zone و لوپ
./run.sh                # رندر کامل ۱۱۴۰ فریم و contact sheet
../../.venv/bin/python verify_video.py
npm run export          # خروجی قابل‌تحویل، بدون بازنویسی ریل اول
npm run test:web        # پخش/متادیتا، Range، دانلودها، گالری و موبایل
npm start               # پیش‌نمایش 0.0.0.0:3000؛ قابل تغییر با PORT
```

- خروجی کاری: `kit/out/05/` (scratch و خارج از Git).
- تصاویر، صوت، گزارش و شواهد تست: `kit/deliverables/reel-05/` (تولیدشده و خارج از Git).
- MP4 نهایی قابل‌دانلود: `kit/deliverables/nail-reel-05.mp4` (بنا به درخواست کاربر در Git).
- گزارش و استوری‌بورد ماندگار: `kit/docs/`.
- پیش‌نمایش از URL نسبی استفاده می‌کند و سرور Range requests برای seek را می‌پذیرد؛ کد مرورگر به localhost سرویس دیگری درخواست نمی‌دهد.

ورودی اصلی هر پنج ریل در `kit/input/scenarios/` بایگانی شده است. `kit/input/scenario.json` ورودی فعال است و برای ریل پنجم سه کلید `reelId`، `renderer` و `audioStyle` اضافه دارد؛ متن پیوست در بایگانی دست‌نخورده است؛ فقط جملهٔ fix در ورودی اجرایی ۰۵ برای دقت آموزشی تعدیل شده است. جزئیات ویرایش و بازسازی نسخهٔ اول در راهنمای ریل دوم توضیح داده شده‌اند.

## معماری و مجوز

تصویرسازی SVG و کاراکترها در `kit/src/scenes/`، موتور زیرنویس در `kit/src/index.html`، سنتز صدا در `kit/audio/` و رندر/تست‌ها در `kit/render/` هستند. تست اختصاصی اتصال‌ها، ضرب‌های تغییر ظاهر و حفظ قبلی‌ها: `node kit/render/journey-test.mjs`. صحنه تابع خالص `window.__seek(t)` است؛ animation CSS یا تایمر زمان‌واقعی نداریم. برای نسخه‌های SVG مسیر CPU Skia استفاده می‌شود. ریل ۰۵ خودکار WebGL2/SwiftShader را فعال می‌کند؛ render target سه‌بعدی 675×1200 است و در فریم خروجی Full HD با متن/SVG با وضوح کامل ترکیب می‌شود.

فونت **محلی** Vazirmatn تحت مجوز OFL در `kit/assets/fonts/OFL.txt` است. شرح اولیهٔ کیت در `kit/README.md` و prototype قدیمی در `kit/reference/` حفظ شده‌اند؛ prototype جزو خروجی نهایی نیست.
